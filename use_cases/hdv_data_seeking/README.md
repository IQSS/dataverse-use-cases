# README
This fictitious use case highlights ways researchers can leverage generalist repositories to find datasets for reuse.

These use cases were made possible by support from the NIH Office of Data Science Strategy/Office of the NIH Director pursuant to OTA-21-009, “Generalist Repository Ecosystem Initiative (GREI)” through Other Transactions Agreement (OTA) Number 1OT2DB000004-01
