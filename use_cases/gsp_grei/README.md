# README

This data sharing use case highlights the Brain Genomics Superstruct Project Open Access Data Release. This project, which presents a carefully vetted dataset of neuroimaging, behavioral, cognitive, and personality data from over 1,500 human participants, is shared in the Harvard Dataverse Repository.

## Citation
Barbosa, S., & Buckner, R. (2026). Harvard Dataverse Repository Data Sharing User Story: Sharing the Brain Genomics Superstruct Project (GSP). Zenodo. https://doi.org/10.5281/zenodo.18489334
