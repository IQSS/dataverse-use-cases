# README

This data-sharing use case highlights CAFE RCC, The Research Coordinating Center for Health and Extreme Weather, a joint initiative of the Boston University School of Public Health and the Harvard T.H. Chan School of Public Health, and its collaboration with the Dataverse Project team at IQSS, Harvard, to develop and sustain a data-sharing environment for its community. Visit the CAFE project for more information about this initiative.
